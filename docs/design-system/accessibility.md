# Acessibilidade

Meta WCAG 2.2 AA. Mantenha foco visível, rótulos explícitos, hierarquia de títulos, landmarks e alternativas tabulares. Não dependa só de cor. Teste teclado, Escape, retorno de foco, zoom, contraste e leitor de tela. Os testes axe do catálogo de visualização verificam apenas regras automatizáveis, não certificam conformidade integral.
