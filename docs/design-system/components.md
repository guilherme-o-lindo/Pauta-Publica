# Componentes

Use Button, Input, Card e Badge a partir dos diretórios `components/ui`. As variantes são definidas em CVA; preserve atributos nativos e estados disabled/focus. FormField fornece id e descrição/erro ao slot. DataTable recebe columns, rows, caption e pageSize; ordenação e paginação locais. PublicLayout recebe items e fornece região main; DetailLayout recebe slots breadcrumb/header/aside. Consulte as stories de cada família para exemplos executáveis.
