# Limitações e escopo

Biblioteca exclusivamente frontend. APIs, backend, autenticação, persistência remota e malhas territoriais reais estão fora do escopo. Os mapas aceitam geometria fornecida pelo consumidor e o catálogo demonstra somente polígonos sintéticos explicitamente identificados. O logotipo permanece provisório e o tema atual é claro. Auditoria manual completa WCAG 2.2 AA e aprovação humana das referências visuais não foram realizadas. Os snapshots Windows não são baselines Linux.
