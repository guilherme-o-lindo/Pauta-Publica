# Tokens

Primitivos em `src/styles/tokens/primitives.css`, papéis em `semantic.css`, dimensões em `components.css` e ponte Tailwind em `theme.css`. Use `bg-background`, `text-foreground`, `border-border`, `rounded-ui-md`. Espaçamento base de 4 px, controles de pelo menos 44 px. Cores de gráficos em `visualization.css` e `lib/visualization/options.ts` devem permanecer sincronizadas.
