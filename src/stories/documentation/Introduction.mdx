# Pauta Pública

Política simples. Informação para todos.

Biblioteca Vue 3, TypeScript, Tailwind e Reka UI, com identidade Brasil plural.

## Como utilizar

Comece pelos tokens semânticos, componha os primitivos e reutilize componentes de domínio. Consulte as stories de cada família para exemplos. Não utilize cores regionais como classificação política.

## Dados e acessibilidade

Todos os dados do laboratório são fictícios. Gráficos precisam de descrição, fonte e alternativa tabular. Mapas exigem geometria territorial de fonte identificada. WCAG 2.2 AA é uma meta, não uma certificação já obtida.
